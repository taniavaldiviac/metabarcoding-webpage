Conexión al servidor y clonación de repositorio Github

1. Conéctate a la VPN

Antes de conectarte al servidor necesitas activar la VPN con el cliente Hillstone Secure Connect:

  • Servidor VPN: 200.23.161.197
  • Puerto: 4666
  • Usuario: BIO\tu_usuario (por ejemplo, BIO\usr01)
  • Contraseña: la que te proporcionó el instructor

2. Conéctate al servidor por SSH

Abre la terminal en tu computadora y escribe:

ssh usrXX@200.23.162.240

Reemplaza usrXX por tu usuario (por ejemplo, usr01). Escribe tu contraseña cuando se te pida.

  • Si es la primera vez que te conectas, puede que te pregunte si confías en el servidor. Escribe yes y presiona Enter.

3. Clona el repositorio del curso

git clone https://github.com/taniavaldiviac/metabarcoding-code.git
cd ~/metabarcoding-code

4. Copia los archivos FASTQ

Los archivos de secuenciación están en el directorio del instructor:

cp /home/tvaldivia/metabarcoding-code/raw_fastqs/* ~/metabarcoding-code/raw_fastqs/

5. Verifica los paquetes de R

Los paquetes necesarios ya están instalados en el servidor. Tu cuenta está configurada para encontrarlos automáticamente. Verifica abriendo R:

R

Dentro de R:

library(dada2)
library(phyloseq)
library(tidyverse)
q()

Si no hay errores, está todo listo.

6. Ambiente conda para herramientas de línea de comandos

Para los pasos de control de calidad y remoción de adaptadores, activa el ambiente metabarcoding:

conda activate metabarcoding

Este ambiente contiene:

Herramienta Uso
cutadapt Remoción de adaptadores y primers
fastqc Control de calidad de lecturas
multiqc Reporte agregado de calidad

Para desactivarlo cuando termines:

conda deactivate

¿Qué contiene este repositorio?

  • scripts/: Scripts numerados en orden de ejecución (bash, R, Quarto).
  • raw_fastqs/: Archivos FASTQ originales.
  • for_dada2/: Archivos procesados listos para DADA2.
  • cutadapt_reports/: Reportes del preprocesamiento con Cutadapt.
  • final_data/: Resultados del análisis (tablas, figuras, RData).
  • metadata/: Archivos de configuración (primers, metadatos).
NotaRecuerda
  • Usa siempre ~/metabarcoding-code como tu directorio de proyecto.
  • Los paquetes de R están disponibles automáticamente — no necesitas instalar nada.
  • Activa conda activate metabarcoding solo para los pasos de QC y Cutadapt.
