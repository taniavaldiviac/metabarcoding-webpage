Dada2 - Dereplicación e Inferencia de Errores

  • Mostrar todo el código
  • Ocultar todo el código
  • Ver el código fuente

Este paso tiene dos partes: primero dereplicamos las lecturas (eliminamos duplicados y contamos abundancias), luego aprendemos el modelo de error de la secuenciadora para poder distinguir errores técnicos de variantes biológicas reales.

Paso 1 — Dereplicación

La dereplicación colapsa lecturas identicas en secuencias únicas y registra cuantas veces aparece cada una. Esto reduce el volumen de datos sin perder información biológica.

Código 
exists <- file.exists(filtFs) & file.exists(filtRs)
filtFs <- filtFs[exists]
filtRs <- filtRs[exists]
sample.names <- sample.names[exists]

derepFs <- derepFastq(filtFs, verbose = TRUE)
derepRs <- derepFastq(filtRs, verbose = TRUE)
names(derepFs) <- sample.names
names(derepRs) <- sample.names

Deberías ver para cada muestra: cuantas lecturas únicas quedaron. Un ratio alto de secuencias únicas / total puede indicar alta diversidad o contaminación; un ratio muy bajo es normal en muestras con taxones dominantes.

Código 
# Diagnóstico rápido de la primera muestra
n_unique_F     <- length(derepFs[[1]]$uniques)
total_reads_F  <- sum(derepFs[[1]]$uniques)
compression_ratio <- round(n_unique_F / total_reads_F * 100, 2)

message("Secuencias únicas Forward: ", n_unique_F)
message("Ratio de compresión: ", compression_ratio, "%")
message("Top 5 abundancias: ", paste(head(sort(derepFs[[1]]$uniques, decreasing = TRUE), 5), collapse = ", "))

if (compression_ratio < 1)
  message("INFO: Baja diversidad (< 1% únicas). Normal en muestras con especies dominantes.")
if (compression_ratio > 50)
  warning("Alta diversidad inusual (> 50% únicas). Revisa calidad del filtrado o contaminación.")

El pipeline guarda las estadísticas de dereplicación para todas las muestras en final_data/logs/:

Código 
derep_stats <- data.frame(
  Sample        = sample.names,
  Unique_seqs_F = sapply(derepFs, function(x) length(x$uniques)),
  Total_reads_F = sapply(derepFs, function(x) sum(x$uniques)),
  Unique_seqs_R = sapply(derepRs, function(x) length(x$uniques)),
  Total_reads_R = sapply(derepRs, function(x) sum(x$uniques))
)
derep_stats$Compression_ratio_F <- with(derep_stats,
  round(Unique_seqs_F / Total_reads_F * 100, 2))
derep_stats$Compression_ratio_R <- with(derep_stats,
  round(Unique_seqs_R / Total_reads_R * 100, 2))

write.csv(derep_stats,
  file.path(output_location, "logs",
            paste0(run_name, "_", primer.data$locus_shorthand[i], "_derep_stats.csv")),
  row.names = FALSE)

Paso 2 — Aprender el modelo de error

La secuenciadora Illumina comete errores al leer las bases (una A real puede leerse como C, G o T). learnErrors() estima estas tasas para cada tipo de transicion (A->C, A->G, etc.) en función de la calidad Phred de cada posición.

El pipeline primero verifica que haya suficientes datos para estimar el modelo:

Código 
nbases_target <- 1e8   # 100 millones de bases (aumentar si tienes > 50 muestras)
max_consist   <- 25    # más iteraciones que el default (10) para forzar convergencia

# Validar datos disponibles
total_bases_F <- sum(sapply(filtFs, function(f) if (file.exists(f)) file.info(f)$size else 0))
total_bases_R <- sum(sapply(filtRs, function(r) if (file.exists(r)) file.info(r)$size else 0))
message("Forward disponible: ~", round(total_bases_F / 1e6, 1), " MB")
message("Reverse disponible: ~", round(total_bases_R / 1e6, 1), " MB")

if (total_bases_F < 1e6 || total_bases_R < 1e6)
  warning("Datos muy limitados (< 1 MB). El modelo puede ser inestable.")
Código 
errF <- tryCatch({
  learnErrors(filtFs, nbases = nbases_target, randomize = TRUE,
              multithread = TRUE, MAX_CONSIST = max_consist, verbose = TRUE)
}, error = function(e) {
  stop("Error al aprender modelo Forward: ", conditionMessage(e))
})

errR <- tryCatch({
  learnErrors(filtRs, nbases = nbases_target, randomize = TRUE,
              multithread = TRUE, MAX_CONSIST = max_consist, verbose = TRUE)
}, error = function(e) {
  stop("Error al aprender modelo Reverse: ", conditionMessage(e))
})

Este paso puede tardar varios minutos. En la salida verás el número de bases usadas y cómo convergen las tasas de error iteración a iteración.

Después de aprender los modelos, el pipeline los valida automáticamente:

Código 
# Validar modelo Forward
if (!is.null(errF$trans) && !is.null(errF$err_out)) {
  message("Transiciones aprendidas: ", length(unique(errF$trans)))
  message("Rango de tasas de error: ",
          round(min(errF$err_out, na.rm = TRUE), 5), " — ",
          round(max(errF$err_out, na.rm = TRUE), 5))
  if (any(errF$err_out > 0.1, na.rm = TRUE))
    warning("Tasas de error > 10%. Revisa calidad de datos.")
}

Paso 3 — Visualizar el modelo de error

El gráfico de errores muestra las 12 posibles transiciones (A->C, A->G, etc.). Los puntos rojos son las tasas observadas; la linea negra es el modelo ajustado. Deben seguir el mismo patrón: la tasa de error cae conforme aumenta la calidad (Q-score).

Código 
plotErrors(errF, nominalQ = TRUE)
plotErrors(errR, nominalQ = TRUE)

El pipeline guarda estas gráficas automáticamente en final_data/logs/:

Código 
png(file.path(output_location, "logs",
              paste0(run_name, "_", primer.data$locus_shorthand[i], "_errF.png")),
    width = 1200, height = 1200, res = 150)
print(plotErrors(errF, nominalQ = TRUE))
dev.off()

png(file.path(output_location, "logs",
              paste0(run_name, "_", primer.data$locus_shorthand[i], "_errR.png")),
    width = 1200, height = 1200, res = 150)
print(plotErrors(errR, nominalQ = TRUE))
dev.off()

Paso 5 — Inferencia de ASVs con dada()

Con el modelo de error aprendido, dada() infiere las secuencias biológicas reales (ASVs) corrigiendo los errores de secuenciación muestra por muestra.

Código 
dadaFs <- dada(derepFs, err = errF, multithread = TRUE)
dadaRs <- dada(derepRs, err = errR, multithread = TRUE)

Al finalizar verás el número de ASVs inferidas por muestra, por ejemplo: Sample 1: 1979 reads in 232 unique sequences, 8 sample sequences, 1.2e+04 input unique sequences.

Código 
# Cuantos ASVs se infirieron en la primera muestra
dadaFs[[1]]

Deberías ver el número de secuencias de muestra (ASVs) vs secuencias únicas de entrada. El ratio refleja cuanto “colapso” el denoising.

:::{.callout-note}
## Recuerda
- `learnErrors()` necesita suficientes datos (al menos varios MB de FASTQ filtrados) para estimar tasas confiables.
- Si el modelo no converge, aumenta `MAX_CONSIST` a 50 o `nbases_target` a `2e8`.
- Los modelos `errF` y `errR` son independientes: las lecturas Reverse suelen tener tasas de error ligeramente mayores que las Forward, y eso es normal.
:::
