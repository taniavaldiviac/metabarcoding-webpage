Paso 1 — Cargar librerias

Código 
library(dada2, quietly = TRUE)     # pipeline principal
library(tidyverse, quietly = TRUE) # manipulacion de datos
library(seqinr)                    # útilidades FASTA
library(ShortRead)                 # lectura/QA de FASTQ
library(digest)                    # hashes SHA1 para ASVs
library(here)                      # rutas relativas al proyecto
library(fs)                        # operaciónes con archivos
library(readr)                     # lectura/escritura de CSVs

set.seed(42)  # reproducibilidad

Si no hay errores, todas las librerias estan disponibles en el servidor.

Paso 2 — Definir rutas y parámetros

Código 
proj_root <- here::here()
setwd(proj_root)

fastq_location    <- file.path(proj_root, "for_dada2")
output_location   <- file.path(proj_root, "final_data")
metadata_location <- file.path(proj_root, "metadata")
primer_csv        <- file.path(metadata_location, "primer_data.csv")

i        <- 1          # fila de primer_data.csv a procesar (cambiar por locus)

here::here() detecta automáticamente la raíz del proyecto (la carpeta donde está el archivo .Rproj), sin importar desde dónde se ejecute el script. Esto evita rutas absolutas del tipo /home/usr01/metabarcoding-code/... que cambian en cada computadora o usuario.

file.path() construye rutas de forma segura uniendo componentes con el separador correcto del sistema operativo (/ en Linux/Mac, \ en Windows). Por ejemplo:

file.path(proj_root, "for_dada2")
# resultado: "/home/usr01/metabarcoding-code/for_dada2"

Es equivalente a pegar strings con paste0(), pero portable entre sistemas.

  • i selecciona el locus a procesar (fila en primer_data.csv)
  • run_name se genera automáticamente con la fecha y hora de inicio y se usa como prefijo en todos los archivos de salida — así cada corrida produce archivos con nombre único

Paso 3 — Leer parámetros del locus

primer_data.csv es el archivo de configuración central del pipeline. Contiene una fila por cada locus/marcador que quieres analizar, con toda la información que el script necesita para procesar ese marcador:

Columna Qué contiene
locus_shorthand Identificador corto del marcador (ej. 12S) — se usa para filtrar los archivos FASTQ y nombrar los outputs
F_qual Secuencia del primer forward
R_qual Secuencia del primer reverse
db_name Nombre del archivo de base de datos de taxonomía en metadata/
max_trim Longitud máxima de truncamiento permitida — evita cortar tanto que se pierda el solapamiento F/R

Si el curso tiene más de un marcador (ej. 12S y COI), cada uno tiene su propia fila y se procesan cambiando el valor de i.

Paso 8 — Cálculo automatico del punto de truncamiento

El script calcula el punto de truncamiento usando una ventana movil sobre la calidad mediana, limitado por max_trim de primer_data.csv para preservar el solapamiento F/R.

Código 
n <- 500000; window_size <- 10

trimsF <- numeric(length(fnFs))
for (f in seq_along(fnFs)) {
  srqa   <- qa(fnFs[f], n = n)
  df     <- srqa[["perCycle"]]$quality
  means  <- rowsum(df$Score * df$Count, df$Cycle) / rowsum(df$Count, df$Cycle)
  window_values <- vapply(1:(length(means) - window_size),
                          function(j) mean(means[j:(j + window_size)]), numeric(1))
  trimsF[f] <- min(which(window_values < 30))
}
where_trim_all_Fs <- median(trimsF, na.rm = TRUE)
if (where_trim_all_Fs > primer.data$max_trim[i]) where_trim_all_Fs <- primer.data$max_trim[i]

# Idem para Reverse -> where_trim_all_Rs

message("Puntos de truncamiento: F=", where_trim_all_Fs, " | R=", where_trim_all_Rs)

Paso 9 — Distribución de longitudes de lecturas crudas (opcional)

Este paso es un diagnóstico previo al filtrado: muestra la distribución de longitudes de las lecturas crudas por tipo (Forward / Reverse). Es útil para detectar problemas de secuenciación o mezclas inesperadas de longitudes. Puedes cambiarlo a FALSE si tienes muchas muestras y quieres acelerar el análisis.

Código 
PLOT_RAW_LENGTHS <- TRUE  # cambiar a FALSE para saltar este paso

if (PLOT_RAW_LENGTHS) {
  sample_n_reads <- 100000
  get_lengths <- function(fq_file, n = sample_n_reads) {
    streamer <- ShortRead::FastqStreamer(fq_file, n = n)
    on.exit(close(streamer))
    chunk <- ShortRead::yield(streamer)
    if (length(chunk) == 0) return(integer(0))
    ShortRead::width(ShortRead::sread(chunk))
  }

  lengths_F <- purrr::map_df(fnFs, ~ tibble::tibble(ReadType = "Forward",
                                                     File = basename(.x),
                                                     Length = get_lengths(.x)))
  lengths_R <- purrr::map_df(fnRs, ~ tibble::tibble(ReadType = "Reverse",
                                                     File = basename(.x),
                                                     Length = get_lengths(.x)))
  lengths_all <- dplyr::bind_rows(lengths_F, lengths_R)

  png(file.path(output_location, "logs",
                paste0(run_name, "_", primer.data$locus_shorthand[i], "_raw_read_lengths.png")),
      width = 2000, height = 1200, res = 300)
  print(
    ggplot2::ggplot(lengths_all, ggplot2::aes(x = Length, fill = ReadType)) +
      ggplot2::geom_histogram(alpha = 0.6, position = "identity", binwidth = 1, color = "black") +
      ggplot2::facet_wrap(~ ReadType, ncol = 1, scales = "free_y") +
      ggplot2::labs(title = "Distribución de longitudes de lecturas crudas (primeras 100k por archivo)",
                    x = "Longitud (bp)", y = "Frecuencia") +
      ggplot2::theme_minimal()
  )
  dev.off()
}

La gráfica se guarda en final_data/logs/ con el sufijo _raw_read_lengths.png.

Paso 11 — Filtrado y trimming

El pipeline valida primero que los puntos de truncamiento sean razonables (mínimo 50 bp) y luego ejecuta el filtrado dentro de un tryCatch para dar un mensaje claro si algo falla. El truncLen está definido en el script — ajústalo si tus perfiles de calidad indican un punto diferente:

Código 
# Validar que los puntos de truncamiento son razonables
if (is.na(where_trim_all_Fs) || where_trim_all_Fs < 50) {
  stop("truncLen_F muy bajo o NA (", where_trim_all_Fs, "). Revisa calidad de Forward.")
}
if (is.na(where_trim_all_Rs) || where_trim_all_Rs < 50) {
  stop("truncLen_R muy bajo o NA (", where_trim_all_Rs, "). Revisa calidad de Reverse.")
}

out <- tryCatch({
  filterAndTrim(
    fnFs, filtFs, fnRs, filtRs,
    truncLen    = c(65, 65),   # ajustar según perfiles de calidad del run
    maxN        = 0,           # elimina lecturas con Ns
    maxEE       = c(2, 2),     # máximo 2 errores esperados por lectura
    truncQ      = 2,           # trunca si encuentra base con calidad < 2
    rm.phix     = TRUE,        # remueve contaminación PhiX de Illumina
    compress    = TRUE,
    multithread = 4,
    matchIDs    = TRUE         # asegura pareado correcto F/R
  )
}, error = function(e) {
  stop("Error en filterAndTrim: ", conditionMessage(e),
       "\nRevisa que los archivos FASTQ existan y no estén corruptos.")
})

Paso 13 — Guardar checkpoint después de filterAndTrim

El pipeline guarda automáticamente un checkpoint .RData después de filterAndTrim(). Si necesitas reanudar el análisis desde este punto (por ejemplo, para ajustar parámetros de denoising sin repetir el filtrado), puedes cargar este archivo:

## Paso 11 — Filtrado y trimming

El pipeline valida primero que los puntos de truncamiento sean razonables (mínimo 50 bp) y luego ejecuta el filtrado dentro de un `tryCatch` para dar un mensaje claro si algo falla. El `truncLen` está definido en el script — ajústalo si tus perfiles de calidad indican un punto diferente:

```{r eval=FALSE}
# Validar que los puntos de truncamiento son razonables
if (is.na(where_trim_all_Fs) || where_trim_all_Fs < 50) {
  stop("truncLen_F muy bajo o NA (", where_trim_all_Fs, "). Revisa calidad de Forward.")
}
if (is.na(where_trim_all_Rs) || where_trim_all_Rs < 50) {
  stop("truncLen_R muy bajo o NA (", where_trim_all_Rs, "). Revisa calidad de Reverse.")
}

out <- tryCatch({
  filterAndTrim(
    fnFs, filtFs, fnRs, filtRs,
    truncLen    = c(65, 65),   # ajustar según perfiles de calidad del run
    maxN        = 0,           # elimina lecturas con Ns
    maxEE       = c(2, 2),     # máximo 2 errores esperados por lectura
    truncQ      = 2,           # trunca si encuentra base con calidad < 2
    rm.phix     = TRUE,        # remueve contaminación PhiX de Illumina
    compress    = TRUE,
    multithread = 4,
    matchIDs    = TRUE         # asegura pareado correcto F/R
  )
}, error = function(e) {
  stop("Error en filterAndTrim: ", conditionMessage(e),
       "\nRevisa que los archivos FASTQ existan y no estén corruptos.")
})
```
