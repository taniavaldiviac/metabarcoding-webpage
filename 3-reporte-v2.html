Golfo de California — Metabarcoding 12S rDNA

Este reporte presenta el flujo completo de análisis ecológico de comunidades de peces en el Golfo de California a partir de datos de metabarcoding del gen 12S rDNA. Partiendo de los archivos .RData generados por el pipeline DADA2, construimos el objeto phyloseq, evaluamos la calidad de los datos, estandarizamos la profundidad de secuenciación y aplicamos análisis de diversidad alfa, composición taxonómica y diversidad beta. Todos los pasos siguen las mejores prácticas actuales para estudios de eDNA en ecología de comunidades.

Carga dinámica de datos

Cargamos todos los archivos .RData disponibles en el directorio de salida del pipeline DADA2. El uso de un loop con new.env() evita que las variables de distintos archivos se sobreescriban en el entorno global. Luego combinamos inteligentemente las tablas track de todos los archivos, y seleccionamos el primer .RData válido (que contenga otu_mat) para construir el objeto phyloseq.

Código

output_list <- lapply(rdatas, function(f) {
  e <- new.env()
  load(f, envir = e)
  as.list(e)
})
names(output_list) <- basename(rdatas)

# Combinar todas las tablas track disponibles
track <- do.call(rbind, lapply(output_list, function(x) {
  if (!is.null(x$track)) x$track else NULL

2. Tabla de rendimiento del pipeline

Track con porcentajes de retención

El seguimiento del número de lecturas a lo largo del pipeline (read tracking) es el primer control de calidad del análisis. Cada etapa — filtrado, denoising, merge, quimeras, filtro de longitud — reduce el número de lecturas. Pérdidas moderadas son normales, pero caídas abruptas en algún paso pueden indicar parámetros inadecuados o muestras de baja calidad.

En esta versión mejorada añadimos columnas de porcentaje de retención entre cada paso, lo que facilita identificar en qué etapa se pierden más lecturas. El porcentaje final (pct_final) refleja la eficiencia global del pipeline: valores entre 70–90% son típicamente esperados.

Código 
track_pct <- as.data.frame(track) %>%
  dplyr::mutate(
    pct_filtered  = round(filtered      / input        * 100, 1),
    pct_denoised  = round(denoisedF     / filtered     * 100, 1),
    pct_merged    = round(merged        / denoisedF    * 100, 1),
    pct_nonchim   = round(nonchim       / merged       * 100, 1),
    pct_final     = round(length_filter / input        * 100, 1)
  )

track_pct %>%

Rarefacción y curvas de rarefacción

La rarefacción estandariza la profundidad de secuenciación al mismo número de lecturas en todas las muestras. Esto es indispensable antes de comparar índices de diversidad entre sitios, ya que con más lecturas inevitablemente se detectan más especies. Usamos phyloseq::rarefy_even_depth() para rarefacer al mínimo de lecturas entre las muestras no-control.

Las curvas de rarefacción muestran cómo aumenta el número de ASVs detectadas al aumentar el número de lecturas submuestreadas. Una curva que se acerca a una asíntota indica que la muestra está suficientemente cubierta; una curva que sigue subiendo sugiere que hay más diversidad por descubrir con mayor secuenciación.

Código 
# Excluir controles antes de rarefacer
ps_filt <- phyloseq::subset_samples(
  ps,
  !grepl("MOCK|CTR", phyloseq::sample_data(ps)$site_id, ignore.case = TRUE)
)
ps_filt <- phyloseq::prune_taxa(phyloseq::taxa_sums(ps_filt) > 0, ps_filt)

# Rarefacer al mínimo de profundidad
set.seed(123)
min_depth <- min(phyloseq::sample_sums(ps_filt))
message("Rarefacción a: ", min_depth, " lecturas por muestra")
ps_rare <- phyloseq::rarefy_even_depth(
  ps_filt,
  sample.size = min_depth,
  verbose     = FALSE,
  rngseed     = 123
)

# Curvas de rarefacción con vegan::rarecurve
comm_rare_input <- t(as.matrix(phyloseq::otu_table(ps_filt)))

abline(v = min_depth, lty = 2, col = "#d73027", lwd = 1.5)

4. Diversidad alfa

La diversidad alfa (α) describe la riqueza y equitatividad de especies dentro de cada sitio. Usamos el objeto rarefaccionado ps_rare para garantizar que las comparaciones entre sitios no estén sesgadas por diferencias en la profundidad de secuenciación.

Calculamos seis índices complementarios:

Índice Qué mide
Observed Número de ASVs detectadas
Chao1 Riqueza estimada (incluye raras no detectadas)
ACE Estimador de cobertura de abundancia
Shannon Riqueza + equitatividad (sensible a especies raras)
Simpson Dominancia (sensible a especies abundantes)
InvSimpson Número efectivo de especies dominantes

Cálculo de índices y boxplots por región

Calculamos todos los índices con phyloseq::estimate_richness() y graficamos la distribución de valores por región del Golfo de California. La prueba de Kruskal-Wallis evalúa si hay diferencias significativas entre regiones.

Código 
alpha_df <- phyloseq::estimate_richness(
  ps_rare,
  measures = c("Observed", "Chao1", "ACE", "Shannon", "Simpson", "InvSimpson")
)
alpha_df$site_id   <- phyloseq::sample_data(ps_rare)$site_id
alpha_df$region_gc <- phyloseq::sample_data(ps_rare)$region_gc

# Reshape a formato largo para ggplot
alpha_long <- alpha_df %>%
  dplyr::select(site_id, region_gc, Observed, Chao1, ACE, Shannon, Simpson, InvSimpson) %>%
  tidyr::pivot_longer(
    cols      = -c(site_id, region_gc),
    names_to  = "index",
    values_to = "value"
  ) %>%
  dplyr::mutate(
    index = factor(index,
                   levels = c("Observed","Chao1","ACE","Shannon","Simpson","InvSimpson"))
  )

# Paleta de regiones (colorblind-friendly: RColorBrewer Set2)
regions     <- unique(alpha_long$region_gc)
pal_regions <- RColorBrewer::brewer.pal(max(3, length(regions)), "Set2")[seq_along(regions)]
names(pal_regions) <- regions

# Kruskal-Wallis por índice
kw_results <- alpha_long %>%
  dplyr::group_by(index) %>%
  dplyr::summarise(
    p_value = tryCatch(
      kruskal.test(value ~ region_gc)$p.value,
      error = function(e) NA_real_
    ),
    .groups = "drop"
  ) %>%
  dplyr::mutate(
    label = dplyr::case_when(
      p_value < 0.001 ~ "p < 0.001 ***",
      p_value < 0.01  ~ paste0("p = ", round(p_value, 3), " **"),
      p_value < 0.05  ~ paste0("p = ", round(p_value, 3), " *"),
      !is.na(p_value) ~ paste0("p = ", round(p_value, 3), " ns"),
      TRUE            ~ "p = NA"
    )
  )

# Unir resultados al dataframe largo para anotar
alpha_long <- alpha_long %>%
  dplyr::left_join(kw_results, by = "index")

# Calcular posición y del texto de anotación (máximo + 5%)
y_pos <- alpha_long %>%
  dplyr::group_by(index) %>%
  dplyr::summarise(y_ann = max(value, na.rm = TRUE) * 1.08, .groups = "drop")

alpha_long <- alpha_long %>% dplyr::left_join(y_pos, by = "index")

ggplot(alpha_long, aes(x = region_gc, y = value, fill = region_gc)) +
  geom_boxplot(alpha = 0.75, outlier.shape = 21, outlier.size = 2) +
  geom_jitter(aes(color = region_gc), width = 0.15, size = 2, alpha = 0.7) +
  geom_text(
    data = dplyr::distinct(alpha_long, index, label, y_ann),
    aes(x = 1.5, y = y_ann, label = label),
    inherit.aes = FALSE,
    size = 3, fontface = "italic", color = "gray30"
  ) +
  scale_fill_manual(values  = pal_regions) +
  scale_color_manual(values = pal_regions) +
  facet_wrap(~index, scales = "free_y", ncol = 3) +
  labs(
    title    = "Diversidad alfa por región del Golfo de California",
    subtitle = "Objeto rarefaccionado — Kruskal-Wallis entre regiones",
    x        = "Región",
    y        = "Valor del índice"

  theme_minimal(base_size = 12) +
  theme(
    plot.title      = element_text(face = "bold"),

    strip.text      = element_text(face = "bold"),
    legend.position = "none",
    panel.grid.minor = element_blank()

5. Curva de acumulación de especies

La curva de acumulación muestra cómo aumenta el número de especies únicas detectadas conforme se incorporan más muestras al análisis. Es fundamental para evaluar la suficiencia del muestreo: si la curva alcanza una asíntota, el esfuerzo de muestreo fue suficiente. Si sigue creciendo, hay diversidad por descubrir.

La banda sombreada representa ± 1 desviación estándar entre permutaciones aleatorias. La línea discontinua naranja muestra el estimador Chao de riqueza potencial total del sistema.

Código

7. Diversidad beta

La diversidad beta (β) mide las diferencias en composición de comunidades entre sitios. El flujo de análisis correcto es:

  1. Verificar homogeneidad de dispersiones (betadisper) — prerequisito del PERMANOVA
  2. PERMANOVA con Bray-Curtis — prueba si las regiones tienen composiciones distintas
  3. ANOSIM con Jaccard — prueba alternativa basada en rangos
  4. NMDS basado en especies — visualización con taxonomía
  5. NMDS basado en ASVs — visualización libre de taxonomía

Preparación de matrices comunitarias

Código 
# Matriz de abundancias por especie (sin controles), muestras como filas

if (phyloseq::taxa_are_rows(ps_sp)) comm_sp_mat <- t(comm_sp_mat)

meta_sp <- as(phyloseq::sample_data(ps_sp), "data.frame")

# Excluir controles dinámicamente (MOCK, CTR)
is_ctrl_sp  <- grepl("MOCK|CTR", meta_sp$site_id, ignore.case = TRUE)
meta_filt   <- meta_sp[!is_ctrl_sp, ]
meta_filt$sample_id <- rownames(meta_filt)

samps_keep  <- intersect(meta_filt$sample_id, rownames(comm_sp_mat))

dist_jac <- vegan::vegdist(comm_filt, method = "jaccard")

message("Muestras en análisis de beta diversidad: ", nrow(comm_filt))

Homogeneidad de dispersiones (betadisper)

Antes de aplicar PERMANOVA es obligatorio verificar la homogeneidad de varianzas entre grupos. Si los grupos tienen dispersiones muy distintas, un PERMANOVA significativo puede reflejar esa diferencia de dispersión y no necesariamente diferencias en la posición de los centroides (composición media).

## 2. Tabla de rendimiento del pipeline

### Track con porcentajes de retención

El seguimiento del número de lecturas a lo largo del pipeline (*read tracking*) es el primer control de calidad del análisis. Cada etapa — filtrado, denoising, merge, quimeras, filtro de longitud — reduce el número de lecturas. Pérdidas moderadas son normales, pero caídas abruptas en algún paso pueden indicar parámetros inadecuados o muestras de baja calidad.

En esta versión mejorada añadimos **columnas de porcentaje de retención** entre cada paso, lo que facilita identificar en qué etapa se pierden más lecturas. El porcentaje final (`pct_final`) refleja la eficiencia global del pipeline: valores entre **70–90%** son típicamente esperados.

::: {.callout-tip}
**Interpretación:** Si la muestra de baja cobertura es un control negativo, esto es esperado. Si es una muestra ambiental real, considera si eliminarla del análisis de diversidad afectaría tus conclusiones.
:::

### Rarefacción y curvas de rarefacción

La **rarefacción** estandariza la profundidad de secuenciación al mismo número de lecturas en todas las muestras. Esto es indispensable antes de comparar índices de diversidad entre sitios, ya que con más lecturas inevitablemente se detectan más especies. Usamos `phyloseq::rarefy_even_depth()` para rarefacer al mínimo de lecturas entre las muestras no-control.

Las **curvas de rarefacción** muestran cómo aumenta el número de ASVs detectadas al aumentar el número de lecturas submuestreadas. Una curva que se acerca a una asíntota indica que la muestra está suficientemente cubierta; una curva que sigue subiendo sugiere que hay más diversidad por descubrir con mayor secuenciación.

```{r qc-rarefaccion, fig.width=9, fig.height=6}
# Excluir controles antes de rarefacer
```

## 4. Diversidad alfa

La diversidad alfa (α) describe la **riqueza y equitatividad de especies dentro de cada sitio**. Usamos el objeto rarefaccionado `ps_rare` para garantizar que las comparaciones entre sitios no estén sesgadas por diferencias en la profundidad de secuenciación.

Calculamos seis índices complementarios:

| Índice | Qué mide |
|:-------|:---------|
| **Observed** | Número de ASVs detectadas |
| **Chao1** | Riqueza estimada (incluye raras no detectadas) |
| **ACE** | Estimador de cobertura de abundancia |
| **Shannon** | Riqueza + equitatividad (sensible a especies raras) |
| **Simpson** | Dominancia (sensible a especies abundantes) |
| **InvSimpson** | Número efectivo de especies dominantes |

### Cálculo de índices y boxplots por región

Calculamos todos los índices con `phyloseq::estimate_richness()` y graficamos la distribución de valores por región del Golfo de California. La prueba de Kruskal-Wallis evalúa si hay diferencias significativas entre regiones.

```{r alfa-calculo, fig.width=11, fig.height=7}
    inherit.aes = FALSE,
    size = 3, fontface = "italic", color = "gray30"
  ) +
  scale_fill_manual(values  = pal_regions) +
  scale_color_manual(values = pal_regions) +

    title    = "Diversidad alfa por región del Golfo de California",

  theme_minimal(base_size = 12) +
  theme(
    plot.title      = element_text(face = "bold"),
    axis.title      = element_text(face = "bold"),
    strip.text      = element_text(face = "bold"),
```

## 5. Curva de acumulación de especies

La curva de acumulación muestra cómo aumenta el número de **especies únicas detectadas** conforme se incorporan más muestras al análisis. Es fundamental para evaluar la **suficiencia del muestreo**: si la curva alcanza una asíntota, el esfuerzo de muestreo fue suficiente. Si sigue creciendo, hay diversidad por descubrir.

La banda sombreada representa ± 1 desviación estándar entre permutaciones aleatorias. La línea discontinua naranja muestra el estimador Chao de riqueza potencial total del sistema.

## 7. Diversidad beta

La diversidad beta (β) mide las **diferencias en composición de comunidades entre sitios**. El flujo de análisis correcto es:

1. Verificar **homogeneidad de dispersiones** (`betadisper`) — prerequisito del PERMANOVA
2. **PERMANOVA** con Bray-Curtis — prueba si las regiones tienen composiciones distintas
3. **ANOSIM** con Jaccard — prueba alternativa basada en rangos
4. **NMDS basado en especies** — visualización con taxonomía
5. **NMDS basado en ASVs** — visualización libre de taxonomía

### Preparación de matrices comunitarias

```{r beta-prep}
# Matriz de abundancias por especie (sin controles), muestras como filas
comm_sp_mat <- as(phyloseq::otu_table(ps_sp), "matrix")
if (phyloseq::taxa_are_rows(ps_sp)) comm_sp_mat <- t(comm_sp_mat)

meta_sp <- as(phyloseq::sample_data(ps_sp), "data.frame")

# Excluir controles dinámicamente (MOCK, CTR)
is_ctrl_sp  <- grepl("MOCK|CTR", meta_sp$site_id, ignore.case = TRUE)
meta_filt   <- meta_sp[!is_ctrl_sp, ]
meta_filt$sample_id <- rownames(meta_filt)

samps_keep  <- intersect(meta_filt$sample_id, rownames(comm_sp_mat))
meta_filt   <- meta_filt[meta_filt$sample_id %in% samps_keep, ]
comm_filt   <- comm_sp_mat[samps_keep, , drop = FALSE]
rownames(comm_filt) <- meta_filt$site_id

# Calcular matrices de distancia
dist_bc  <- vegan::vegdist(comm_filt, method = "bray")
dist_jac <- vegan::vegdist(comm_filt, method = "jaccard")

message("Muestras en análisis de beta diversidad: ", nrow(comm_filt))
```

### Homogeneidad de dispersiones (betadisper)

Antes de aplicar PERMANOVA es **obligatorio** verificar la homogeneidad de varianzas entre grupos. Si los grupos tienen dispersiones muy distintas, un PERMANOVA significativo puede reflejar esa diferencia de dispersión y no necesariamente diferencias en la posición de los centroides (composición media).


::: {.callout-note}
**Recuerda:** Si el p-valor de `betadisper` es < 0.05, las dispersiones son heterogéneas entre grupos. En ese caso, interpreta el PERMANOVA con precaución: la significancia puede deberse a diferencias en dispersión, no solo en composición media.
:::

### ANOSIM — Jaccard

ANOSIM es una prueba no paramétrica alternativa basada en rangos de distancias. El estadístico **R** oscila entre -1 y 1: valores positivos altos indican que las diferencias entre grupos superan las diferencias dentro de cada grupo.


:::

## 8. Control positivo — MOCK

La muestra MOCK es un control positivo que contiene una mezcla conocida de ADN de especies en proporciones definidas. Permite validar la fidelidad del pipeline de extremo a extremo: ¿detectamos las especies esperadas? ¿aparecen especies que no deberían estar?

**Detección dinámica:** en lugar de usar el nombre exacto de la muestra (que puede cambiar entre corridas), detectamos la muestra MOCK automáticamente usando `grepl("MOCK", site_id, ignore.case=TRUE)`.
